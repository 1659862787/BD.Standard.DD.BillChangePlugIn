# BD.Standard.DD.BillChangePlugIns 项目说明

## 项目概述
本项目是基于金蝶BOS（Kingdee BOS）平台的业务插件扩展库，主要用于定制和增强金蝶ERP系统中各类单据的操作校验、界面增强及自动化业务逻辑。

---

## 核心模块：Calculation (MRP与生产订单计算)

该模块主要处理MRP计划运算、生产订单及采购申请单相关的业务逻辑增强与校验，是本项目的核心功能域。

### 1. BOM最高版本获取与更新
- **`HighVersionBomDatas.cs`**：核心工具类，封装金蝶标准API `BOMServiceHelper.GetHightVersionBom`，根据物料ID、组织ID及辅助属性获取最新的BOM版本数据集合。
- **`MrpWizardForm.cs`**：计划运算向导表单插件。监听 `F_HighVersionBom` 按钮点击事件，遍历向导分录实体，调用 `HighVersionBomDatas` 自动将所有物料的BOM更新为最高版本。
- **`ProOrderBillPlugin.cs`**：生产订单表单插件。监听 `F_BOMChange` 菜单按钮点击事件，遍历生产订单分录，一键将分录行物料的BOM版本刷新为最高可用版本。

### 2. 收货确认单日期校验
- **`DeliveryConfirmBillPlugIn.cs`**：收货确认单表单插件。
  - **值改变校验**：当到货验收日期（`F_QEBI_Date2`）改变时，实时校验其必须大于发货日期（`F_QEBI_GYDATE`），否则报错。
  - **保存前校验**：在单据执行保存操作前，再次拦截并校验日期逻辑，不满足则阻断保存（`e.Cancel = true`）。

### 3. 采购申请单操作控制
- **`PURRequisitionSavePlugIn.cs`**：采购申请单操作服务插件，主要在 `BeginOperationTransaction` 中拦截处理：
  - **提交校验与附件上传**：提交时遍历明细物料，校验“采购图片”标识与实际图片附件的一致性；若校验通过，将物料图片转化为Base64，调用 `WebApiServiceCall.AttachmentUpload` 自动上传附件。
  - **撤销与反审核清理**：执行撤销或反审核操作时，直接通过SQL删除关联的附件数据（`T_BAS_ATTACHMENT`），保持单据与附件状态的一致性。

## 其他辅助模块

### 单据变更与审核 (`AduitOperation`, `SaveOperation`)
- **生产项目审核**：审核时自动反写并更新源单数据，支持明细的新增（A）、修改（B）、删除（D）操作。
- **变更单保存校验**：保存时校验变更状态与源单关联数量，防止违规新增、删除或数量倒挂。

### 业务操作与校验 (`CarryOperation`, `SaveX`)
- **BOM版本携带**：审核时通过执行存储过程校验并携带BOM版本。
- **调拨单保存/反审核控制**：限制项目仓与非项目仓数据共存，及控制已推送项目仓数据的反审核权限。

### 列表与表单界面增强 (`PickMtrlListPlugin`, `PickMtrlListPluginList`)
- **简单生产领料单**：动态修改表单标题，针对特定单据类型（如辅料领料单）定制操作成功提示及列表过滤条件。

### 采购询价业务 (`Inquiry/`)
- **采购询价单生成**：支持从采购申请单下推生成询价单，并利用 EPPlus 将数据按模板导出为 Excel 供下载。
- **询价单保存处理**：自动比对各供应商报价，将最低价格及对应供应商反写至采购申请单。
- **询价单数据引入**：处理前端上传的Excel文件，解析并补充行号信息。

### 生产订单锁库管理 (`StartLocks/`)
- **开工锁库校验与执行**：生产订单开工前校验线边仓库存，充足时自动调用WebAPI生成形态转换单进行锁库。
- **反计划解锁**：反执行至计划时，自动反审核并删除锁库的形态转换单，释放库存占用。

### 通用工具 (`Logs`)
- **日志记录**：提供简单的文本日志写入功能，用于调试和关键操作记录。
